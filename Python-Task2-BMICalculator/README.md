# Task 2: Body Mass Index (BMI) Calculator

## Overview
A Python-based command-line tool that calculates a user's Body Mass Index (BMI) based on weight and height, categorising the result into WHO health ranges.

## Features
- Interactive CLI prompt.
- Calculates BMI using: weight / (height^2).
- Classifies BMI into Underweight, Normal, Overweight, and Obese.
- Robust input validation for positive numbers.
